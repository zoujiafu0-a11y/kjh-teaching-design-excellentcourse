# P02068 去人像教学文字
来源：C1000《小壁虎借尾巴》第二课时原页P02068。公开版本排除原页学生照片，原件仅在本地保留。

学习目标：发现小壁虎尾巴再生的现象，会尝试提出问题并寻求答案。
评价任务：提出关于小壁虎尾巴再生的问题，并尝试解答。
评价标准：提问并尝试探究小壁虎尾巴的再生之谜。
评价方式：自评、师评（各2星，原表空白）。
学习任务：
（1）学生对小壁虎尾巴再生的现象提出疑问：“小壁虎为什么能长出新尾巴？”
（2）尝试通过观察课文插图和借助AI小博士等方式找答案。
设计意图：培养学生的问题意识和解决问题的能力，拓宽学习的渠道。

板书设计：小壁虎借尾巴；断尾逃生→拨水→赶蝇子→掌握方向→长出新尾巴。（原板书以小壁虎、小鱼、老牛、燕子图及箭头表示对应关系。）

原页右上学习任务嵌图中的学生面部照片未纳入此公开文字稿；没有复写学生身份信息。图像不作为真实学习效果的证据。
