# 批次17：P01441至P01449全文与原页核对

## 朱静《10的再认识》P01441至P01445
与徐欢同题但七栏目：课前准备、情境导入回忆旧知、探究新知构建体系、对比创建认识数位、反思总结对比体会、巩固练习内化提升、布置作业。总结在巩固前，不擅自移到末尾。生日会数字卡9与10的比较导入，任务一数摆11、任务二生活十组、任务三捆十、任务四制作计数器、任务五圈十练习，与学习单明确对应。先材料包（底座小棍珠子）一杆十珠，再两杆一珠表示十；预设去掉十位杆只留右杆一珠以节约器材，让学生解释位置必要性，再命名个位十位。比较10与0至9、0占位，练习后作业记录生活十组发现及完成另练习单。无设计意图段。

P01443 L23至L27：“刚才的10个一，和现在的1个十，都表示的是哪个数呢？”承接亲手捆小棒，功能是比较不同表达下数量不变。P01444 L14至L19移动珠子并去一杆的提问，功能是改变位置/结构后的反证与规范命名，不可脱离已构建两档计数器和十进约定。P01445 L11至L12后作业“把你们的发现记录下来”规定产出而未规定图表版式，应保留其开放形式，不加通用评分表。

源文问题：P01441目标2确有“直的含义观操作”的串字错误；P01443一捆铅笔/一盒鸡蛋十个是例示不适用所有商品；十进计数起源于十指的历史解释未另考证，复用标待核。生日会父母异地工作、小芳生日均预设情境，不迁移为真实学生家庭事实。各页无真实学生身份。

## 吕春女《11～20的认识》P01446至P01449
独立课前准备后原文一级编号一创设情境、二操作活动、三多元表征，后又三借助数轴、四生活中的数、五回顾反思、六课后作业，编号重复需记录，不能误认六环节而删除一段。抓12根数后整理一捆2根认识十二，再任抓11/15/18归十几共同组成，19添1捆成20。计数器与数字卡先表示12，数字卡“1 2”与“10 2”对比，三表征联系；再20与零占位，20的2与12的2对照。数轴10/20定位后给11/12/15/18找家，猜组成/相邻/大小，再问10左20右，生活数仅一句找一找无具体照片，最后一数开花作业。

P01447 L26至L30先问“谁摆的对？这样摆表示什么意思？”再逐位解释，最后“小棒、计数器、数字卡片，这三种表示方法之间有什么联系？”功能先判断、说明意义、跨表征对应，不能只贴三图称已沟通。P01448 L10至L14“20中的‘2’和12中的‘2’，表示的意思相同吗？”以相同数字不同数位控制比较，后面各自十/一及推广位置意义。P01449 L17“一数开花”在11～20选喜欢数多方法表示，原文不规定花形模板/每瓣项目/固定方法数，不能凭名称补齐。目标1“这些数由1个十几个一”应分清20两十例外，正文已单独展开；不能照抄成20也是1个十若干规范个位。无真实学生信息。
