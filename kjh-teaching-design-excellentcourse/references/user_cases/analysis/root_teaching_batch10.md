# 原图全文阅读 P01760—P01769 比尾巴两课时

十页均完整查看原图并阅读。第一课时六页，第二课时四页。目标、重点难点之后无设计意图栏目，过程由口播、预设学生发言和课件动作交织构成。

第一课时六部分：情境导入猜比什么、初读找谁来比、练习问答了解特点、引导说话创编、巩固字词写字、总结。导入由金鱼老虎尾巴猜物正“巴”轻声和识尾，再介绍比尾巴大赛学“比”。初读先听老师读、标四小节、读准音并画动物，再图文连线及分类。读音分类子轻声与后鼻音，另按脚和翅膀分类，再用两种完整列举句宣布名单。分类需要依实际动物信息，不能将原稿“猴子四条腿”等表述作为无争议科学分类迁移。

问句先发现问号，再教师范读、长句停顿、强调比的项目与“谁”，随文识长短伞把；答句明确对应动物特点后朗读，三问三答转分角色。尾巴用途和字形演变是原稿解释，不替代当前生物学和字源核验。背一二节后，让猫鼠燕子参加，先说特点再编问句、看图答。写字先竖提，再比长对照、分字观察范写、描一个写一个、评价建议，最后总结预告下一轮。不强加自评表或额外课后成果。

第二课时五部分：回顾、读中感悟、想象创编、写字、总结。先全文朗读再读脱离课文的动物特征词、背前两节，进入第二轮三四节。先读问答，找弯扁最好看，生活举弯物，讨论“最好看”允许不同标准，再学“最”生活造句及问答，背三四节。孔雀最好看保留为文中作者表达，不写成客观唯一结论。

创编先完整背课文，再加赛耳朵（兔猫象）和嘴巴（鸟鸭兔），分别先提议比什么再问答，接家庭问答游戏。书写“巴、公”，部首八字头与公母语义联结，观察书空、描写、评价后再总结。末鼓励把编的儿歌画写分享，属于本稿课后延伸，不移到第一课时当同一任务。口播“你们都见过”等是预设泛称，不转为新班已调查事实；示例写字优缺点没有真实字迹实证，不能记为新课堂反馈数据。
