# 批次13：两份《图形的认识》P01415至P01422

## 佘雪珠 P01415至P01419
七个一级栏目：复习引入、制作名片、分类寻同、拼搭图形、了解榫卯、卷折纸张、数学实践；课中宣告五活动指中间五项，不含引入和后实践。三目标一重点一难点。先四种图形回忆，再任选一种做名片填信息，随后四图分两类的三个标准，再星级自选拼搭，讨论同种和异种组合并数机器人；接榫卯配对与鲁班锁，折纸/卷纸的平面立体联系，最后知识图及废旧物品挑战。不能压为固定四环节，不能把“发展创新意识”目标变为本次作者自主改写许可。

P01416 L3至L4：“现在，请同学们任选其中一种立体图形，结合自己之前所学的知识，给它做一张名片吧。记得要把相关的信息填写清楚。”前提已列四种并具已有认识，功能明确选择范围、成果形式、信息要求；名片姓名和相片是图形拟人化空白栏，实际无学生身份，不应删原页。P01417 L8至L9让学生选择星级拼，表中1至4星对应两圆柱、两正方体、两长方体、四正方体，不可把星级当实测能力或其他任务统一分层。P01418 L16至L21视频折纸后说发现，再追问还可变什么、卷两个方向、归纳联系，迁移需新材料真实支持，不能虚构视频内容。

事实边界：P01416把长方体全六面说成长长方方不覆盖有正方面的特例，P01417球与正方体分类用“每个面都一样”只是源文通俗说法，不作为球有平面的严格定义。两圆柱拼成圆柱须底面吻合且轴线一致，四正方体“只能拼长方体”限所示完整规整拼法，不能排除任意造型。P01418榫卯建筑事实和P01419华罗庚引语仅源文提出，未外部核验，不得继承成已核实史实。原机器人图清晰，未另逐项给数量答案；不宣称完成题解验算。

## 樊丽秀 P01420至P01422
五栏目含课前准备、创设情境复习关联、创意拼搭复习巩固、综合运用提升思维、课后实践延伸拓展。与前篇同题不同设计：环保小卫士情境、课前收集废品和正方体，辨模型兼咖啡杯反例，回书整理知识图/树；三活动巧搭汽车、搭稳搭高、创意搭并数机器人，再生活拼搭；综合先想再拼四方体，预设四块能大正方体的错误并验证八块，拼形组合连线；总结环保，再家长合作找建筑形状，数学小报或视频介绍。

P01421 L20至L22每人搭一次、展示同组各作、交流稳球方法与长方体竖横差异，功能是同材料条件下操作比较，不能只保留“又稳又高”口号。L27至L28：“数图形的时候可以从上往下或者从左往右按顺序观察，还可以做好标记，这样就不容易数错。”承接已搭机器人计数，可直接复用到需防重漏的类似图形计数，新图数量应重核。P01422 L19要求独立做，困难才用正方体拼，再交流动手操作/观察对比方法，体现先独立与按需支架，不能改成教师全程示范。L24至L25后实践含找建筑、了解形状、形成可展示产出，不能强加全课作业都需视频。车轮圆柱描述限近似模型；球放稳要实际支撑；八方体成大立方体要相同小方体且实心完整更大整体等前提。实际各页无真实学生身份，废品照片无人物。
