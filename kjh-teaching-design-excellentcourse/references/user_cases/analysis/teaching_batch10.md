# 批次10：两份《9加几》P01387至P01398

## 刘碧莲 P01387至P01392
四大环节创设情境导入新课、交流实践探究新知、跟进练习巩固提升、回顾整理反思提升。三目标、一重点一难点。运动会大情境中先10+5唤起十加几，再8+5暂存，后饮料9+4作为主问题；四人合作用数、接数、小棒、点子图多种方法，教师回顾两种操作后比较共同点，问为什么凑十，再命名，枝形图记录，并预设4是否可分2和2的质疑。练习圈算说，再同图找蜜蜂/花两组信息，再连同值卡片比较计算与不计算的解释，最后排算式发现规律，点子图解释少掉1。总结回扣转化，回到导入暂存8+5，留后课探索。各处设计意图分布随具体活动，没有固定每段一条规则。

P01388 L15至L17：“如果觉得计算有困难，可以四人小组合作，还可以用学具代替饮料试着动手数一数、摆一摆，或者画一画，计算结果。并在小组内说说自己的计算方法。大家依次分享讨论的成果吧。”上下文是9+4尚待解决，功能是选择支架、明示操作、表达和交流顺序；替换饮料及组织人数须有新任务依据，不能把四人变成所有任务固定要求。P01389 L7追问“为什么都要先凑成十呢？这样做有什么好处吗？”紧接方法共同点，负责从操作比较转入算法价值解释；不能只引用凑十命名略去理由。P01391 L20“少的那个1去哪里了呢？”紧接个位比另一加数少1的发现，后以点子图解释，不可脱离进位图和相应数域。P01392末页有实质结尾和意图，非空白。源文“最简便”是预设观点，不是经比较测定的普遍结论。未见学生身份，计划使用学生操作视频不等于所附页含真实学生影像。

## 黄玉姣 P01393至P01398
同题不同设计，不是刘碧莲版本修订。教材日期2024年8月不同于前篇7月。课前自我介绍后四大环节：游戏导入联结旧知、情境引入探究新知、分层练习巩固新知、课堂总结升华效果。鸡蛋散放/十个成盒比较引出10+2；牛奶情境9+4，先点数接数和计数器进位，再小棒摆放达到一眼看出的目的，提出拿一根而非两三根的原因；然后两种拆法比较，记录凑十过程，再选喜欢的方法。练习圈图及枝形图、9加数格、排序规律、点子图个位解释，接9+10不进位区分。总结细分谈收获、自我评价、儿歌，不应与另一篇后课问题合并成统一模板。自评只写点亮智慧星，无具体星级量表，不能编造标准为原已有。

P01395 L6至L8学习要求：“自己试着动手摆一摆。”“说一说摆放的过程及原因。”前句指定操作，后句要求过程和因果说明，不能只保留摆出的答案。L11追问为什么拿1而非2、3，在学生完成移动后承担依据核查；L17至L28两方法共同点、不同点、便捷性、算式记录、个人选择依序展开。P01397 L25“少的那个1哪去了呢？”前提同上篇，但本篇后面另讨论9+10，必须分别保留范围。

实际原图确认的问题，隔离不用作正确可复用内容：P01395第二拆法写把左边7根给右4根，且左剩3，与9+4数量不一致；原页确实如此，不能静默当6根改写后说直接沿用。P01396原图9+9=10错误。P01397例述“和的个位是3，第二个加数是2”不符合所列9加几。P01394 OCR把“十三”误成“十二”，原图明确十三，此处是OCR错误，不能错误归责原文。P01398只有儿歌末句与模板备注，仍是有文本尾页。学校教师署名为公开课程自我介绍，未见真实学生信息。
