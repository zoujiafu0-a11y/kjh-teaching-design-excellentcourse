# 批次18：闻鹏《11～20的认识》P01450至P01455

全文与原页逐页核对。三目标、一重点一难点；五大环节在情境中多方法数数表示数、计数器认11至20、练习巩固拓展、数学文化感受计数发展、总结反思积累经验。与吕春女课的12起点和数轴活动不同：本课数学绘本古人摘11果子起点，任务一数果子三作品，任务二用石头表11三作品。点数/圈十/小棒之后11小石、大石十加小石一、两同小石无标记的辨析，再通过标个位十位使两小石可表11，联计数器。计数器教11写读，直接19加1拨20（中间12至19具体拨数活动未逐条写出，不补造）。练习串珠12、棒16、珠19，再尺补11/15/17/19与数序，文化比较古埃及象形和现代位值，最后生活找数讲故事或研究自己提出问题。设计意图随各大段出现。

P01452 L6至L8问大石小石分别表示什么，明确十与一的约定；L9至L18两同小石先判断，再想办法使他人明白，再对照为何现在可以，句子功能是暴露编码歧义、提出标注支架、解释位置的意义。P01453 L4至L7“数位和小石头让你想到了什么？”把刚解决的石头编码联已有计数器，避免无承接宣布位值。P01454 L14至L18尺上补数后问发现，承担数点对应与顺序大小归纳，依赖尺从左到右递增，不能抽成所有方向前后数概括。P01455 L11预设提出其他数位和更大数问题，教师肯定并转课后研究，问题来自该课已形成理解，不应在任何课机械加更大范围探究。
