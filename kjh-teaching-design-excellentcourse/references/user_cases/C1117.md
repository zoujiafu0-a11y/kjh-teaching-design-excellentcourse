# P02478 去人像教学文字
来源：C1117《语文园地一》第二课时原页P02478。公开版本排除原图儿童照片；保留以下任务文字。原教材及练习微图的小字有部分不可辨，不能冒充已逐字转录。

2.讨论交流，体会词意：读了这些词语，你们有什么发现？
（1）借助课文《小蝌蚪找妈妈》插图，学生交流“迎”与“追”的不同。
（2）播放视频，体会“迎”“追”的不同意思。
3.自主表演，体会动词意思：引导学生体会每组中加点词的不同意思，选一组演一演，并交流。
（1）第二组词语“穿衣裳”和“披红袍”：学生表达后，进行小练习。（出示（ ）裙子、（ ）斗篷。）
（2）第三组词语“甩甩手”和“摇摇头”：结合学过的课文《小壁虎找尾巴》《小蝌蚪找妈妈》和表演体验，体会“甩甩”和“摇摇”的区别。
4.任务单巩固，归类拓展。
（1）第一个挑战“词语找朋友”：根据图片，在括号里填上恰当的表示动作的词语。
（2）第二个挑战“词语排排队”：按照速度由慢到快排列不同程度的动词。
（3）第三个挑战“词语回到家”：在语境中将区分相近的动词，选择合适的词语填入括号中。
（二）学习运用句式
1.回顾课文，感知句式
（1）指名读两个句子。
（2）结合加点的词语感悟句子：读了句子，你知道了什么？
2.分层练习，运用句式：指导学生用上加点的词，说自己的日常生活。
（1）可以借助老师的提示说一说。
（2）可以自己选择内容说。（多角度说自己的日常生活）
（3）学生交流
活动三：运用密码，帮助企鹅
1.学生针对题目，提出疑问：企鹅为什么要寄冰呢？企鹅给谁寄冰？从哪寄到哪呢？他用什么方法寄冰呢？最后他寄冰成功了吗？
