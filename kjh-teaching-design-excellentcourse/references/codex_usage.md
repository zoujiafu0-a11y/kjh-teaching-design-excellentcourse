# 使用与目标管理

可直接说明：使用 $kjh-teaching-design-excellentcourse，严格以我指定的完整案例为范本，先读全部原页和配套，逐段逐句复用适用原句，仅替换本次真实教材及对象所需事实；保留原结构和句序，缺写法或材料明确标出；在模板副本制作可编辑Word并检查最新全部页。

提供自然语言和已有材料即可，不要求用户填写JSON。课堂形式、AI、时间、署名、板书和图源按当前要求及主范本，缺项不编，不默认新增四环节或三标签。仅方案、脚本或片段验证按对应范围，不扩制作整套资源。

正式目标只在用户明确要求时调用，先读取已有状态，不覆盖无关目标，不自设预算或定时任务。原件、范本逐句对应、事实替换、模板及最新页面证据内部保留；全部适用必需工作完成才记complete，工具限制如实说明。

交付当前要求的正式成果。AI成品或分析报告只有纳入范围时才额外交；脚本不冒充媒体、估时不冒充实讲，来源与视觉检查不互相替代。参数见[工具](tools.md)。
