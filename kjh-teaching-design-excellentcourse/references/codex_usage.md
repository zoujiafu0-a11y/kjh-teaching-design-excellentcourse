# Codex使用与目标管理

自然语言给出课题、年级、材料、课堂形式与实际展示时限即可，已有附件不重复索取。默认subject、无生、AI开启；小学10至15分钟，中学15至20分钟，范围内选择值记录为设计选择，用户/通知优先。明确阅读课时按reading_course.md及六篇原创案例，不把普通语文课自动判为阅读课。

用户只要方案时交方案，只要AI脚本时交脚本，不自动制作Word或媒体。要求制作则持续推进到适用验收，生成任务独立input/work/final、日志与质量报告。研究、来源、参数、时间、任务评价、原稿诊断、案例迁移及最新页检查均留痕。阅读主稿按阅读模板，学科主稿按学科模板和条件适用的四环节三标签。

## 可复制的目标指令

使用 $kjh-teaching-design-excellentcourse，在指定工作区完成本课。先理解课程类别、课型和阅读/知识起点，保护原件，查看适用案例及真实教材或原书，核验版本与选段，完成目标任务评价、必要AI脚本及模板副本Word。正式目标覆盖全部已要求的交付、来源、内容、时间、可编辑与最新全部页面验收。先读取现有目标；没有未完成目标才登记，同一目标继续，无关目标不覆盖，不擅设预算。工具不可用时如实记文件进度。只有全部适用必需项完成才标记complete。发现问题直接修复，报告真实缺项；脚本不冒充媒体，设计估算不冒充实体试讲。具体课程参数使用本次已提供信息。

正式目标仅在用户明确要求时登记。维护work/progress.md，记录已完成、证据、问题与下一步；暂停、阻塞和完成遵守当前工具规则。阅读课不以教材学情未入主稿或没有固定环节/三标签判失败；材料研究和具体任务仍必须完成。地方赛事无通知不杜撰指标，不承诺获奖或检测结果。

交付final/教学设计.docx、适用final/ai_teaching_script.md、按需final/design_analysis.md及change_log.md、quality_report.md。work保留intake.json、manifest.json、notice_requirements.md、source_log.md、curriculum_research.md、case_review.md、case_transfer.md、draft_diagnosis.md、objective_task_evidence.md、timing_plan.md、image_sources.md、artifact.md、pedagogical_review.md、acceptance.md、page_review.md和progress.md；条件记录按实际需要，缺失不得假写通过。源码与命令见[辅助程序](tools.md)。

## 人工智能教育调用

使用 $kjh-teaching-design-excellentcourse，制作四年级人工智能教育课《人工智能的神奇耳朵》，按附件课程材料和模板，展示12分钟，默认无生及AI赋能。先对标ai_03与ai_07，核验类比与语音处理表述，完整写课程分析、学情、目标、重难点、四环节过程、评价和后续任务。

上述参数仅为调用示例，不自动带入下一课。要求追求目标模式时，目标应包含课程分流、所选原图实际查看、整篇写作、技术核验、通用模板和全部适用验收及交付；未要求正式目标时只维护文件进度。
