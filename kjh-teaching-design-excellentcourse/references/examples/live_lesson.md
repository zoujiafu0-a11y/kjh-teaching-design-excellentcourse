# 教学目标
1. 学生借助圆柱的切割图，想象不同切法得到的截面形状，用图画或语言表达自己的猜想，体会立体图形与平面图形的联系。
2. 学生借助水面验证猜想，能说明观察过程，并根据结果修正判断。
3. 学生结合操作比较图示截面的大小，能在练习中说明判断依据。
# 教学重点
1. 学生想象圆柱按图示切开后的截面形状，借助水面进行验证。
2. 学生比较图示截面的大小，发现截面与切法、切割位置的关系。
# 教学难点
学生理解水面与截面的对应关系，能从合适的方向观察，并结合实验结果解释或修正自己的猜想。
# 教学过程
[h2]课前准备
教师准备规则的透明圆柱形、圆锥形密闭容器，有色水和托盘，并检查容器是否漏水。教师课前另备按图示位置切开的圆锥软泥模型，供学生观察竖切截面。
每组学生准备一个装有少量有色水的透明圆柱形密闭容器和记录用纸。教师课前试摆容器，选择水面边界清楚的水量；斜放时，教师注意让水面不碰到容器的上下底面。
本课安排1课时，按40分钟组织以下活动。
[h1]一、观察切割情境，提出研究问题
[h2]（一）联系已有认识，认识截面
师：同学们，圆柱的底面在哪里？如果把它切开，新出现的面会是什么形状呢？
学生指认圆柱的底面。教师结合模型指出：我们把切开后新出现的平面叫作截面。
师：今天，我们就来学习《切开立体图形》，看看立体图形切开后会出现怎样的平面图形。
[h2]（二）观察三种切法，提出猜想
[img]cuts
师：请同学们看看这三幅图。圆柱分别是怎样切的？你能用手势表示吗？
学生对照图示，用手势表示横切、竖切和斜切。教师引导学生注意图中切入的方向，并把三种切法写在黑板上。
师：请你先在脑中想一想，再把这三种切法得到的面画下来。如果你拿不准，可以在旁边做个记号。
学生独立画出猜想，在同桌之间交流。教师了解学生对哪幅图有不同判断，暂不公布答案。
[intent]【设计意图】教师从学生熟悉的圆柱入手，让学生把想象的截面画出来，了解学生已有的认识。教师保留不同猜想，为后面的操作验证留下需要解决的问题。
[h1]二、借助水面验证，认识截面形状
[h2]（一）交流猜想，寻找验证办法
师：刚才，同学们画出了自己的想法。哪一幅图你比较有把握？哪一幅图还需要再想一想？请你说说理由。
学生结合图示交流猜想。如果学生对斜切的结果有不同意见，教师将相关图画并列展示，引导学生把判断的依据说清楚。
师：大家的想法不完全一样。我们可以怎样验证呢？
学生提出验证办法。教师拿出装有少量有色水的透明密闭容器，引导学生关注水面。
师：我们可以借助水面来观察。你看，水面把容器里面的空间分成了上下两部分。假如沿着水面的位置切开，切开的面就和这里的水面对应。
[img]water
[h2]（二）对照图示摆放，观察水面形状
[h3]1. 师生共同明确观察要求。
教师将圆柱形容器直立摆放，待水面稳定后，请学生从水面的正上方观察。学生把水面的位置与教材中的横切图对应起来。
师：现在，水面对应的是哪一种切法？如果换一种摆法，水面相对于圆柱的位置会怎样变化？请你们在小组里试一试。
教师说明操作要求：学生按图示依次把容器直立、横放和斜放；每次摆好后，学生都要等水面稳定，再从水面的正上方观察。学生观察斜放的容器时，要让水面不碰到上下底面。学生始终拧紧盖子，避免漏水。
[h3]2. 学生操作，记录观察结果。
小组成员轮流摆放容器，其他成员观察水面。学生在自己的猜想旁画出观察到的形状，并在组内说明两次记录是否相同。教师巡视，重点查看学生的观察方向是否合适。
如果学生只看容器侧面的水线，教师引导学生找到水面所在的平面，再调整视线。教师提醒学生：容器虽然换了方向，静止的水面仍保持水平。
[h3]3. 学生汇报，比较猜想与结果。
师：请一组同学来演示。你们怎样摆放容器？观察到了什么形状？它对应哪幅切割图？
学生边演示边交流。教师结合教材图示，引导学生明确：按图中方式横切，截面是圆；竖切，截面是长方形；斜切，截面是椭圆。
如果学生把横切的圆看成了椭圆，教师请学生改变观察方向，从水面正上方再看。如果学生对斜切的结果仍有分歧，教师帮助学生调整容器倾斜程度，在水面不碰到上下底面的情况下重新观察。
师：请你看看刚才画的猜想。哪些地方与观察结果相同？哪些地方需要修改？你准备怎样说明修改的原因？
学生修改自己的记录，并向同桌说明依据。教师关注学生能否把摆放方式与看到的形状对应起来，不只检查图形名称。
[h3]4. 教师小结。
师：同学们，我们借助水面验证了刚才的猜想。同一个圆柱，按照图中不同的方向切开，截面的形状会发生变化。遇到拿不准的地方，我们可以再操作一次，用观察到的结果帮助自己判断。
[intent]【设计意图】学生借助水面观察难以直接想象的截面，将猜想与操作结果进行比较。教师针对观察方向提供指导，让学生知道结论需要有依据，也让学生经历修改原有判断的过程。
[h1]三、改变切割位置，比较截面大小
[h2]（一）观察切割图，提出大小问题
[img]sizes
师：我们已经知道，切开的面可能有不同的形状。请看这四组图，同一个立体图形按图中的方向切，在不同位置切开的面大小一样吗？
学生独立观察，按图从左到右记录自己的判断，再与同桌交流。教师引导学生分清：每次比较的是同一组图中的几个截面。
[h2]（二）比较横切的截面，验证判断
师：我们先看前两组。圆柱横着切，几个面大小怎样？圆锥横着切呢？你是怎样想的？
学生结合圆柱上下粗细相同、圆锥靠近顶点处较细的特点说明猜想。教师请学生观察直立的透明圆柱容器，改变水量后比较水面大小，再用圆锥容器作相应演示。教师每次加水后都把容器放稳，待水面稳定再组织观察。
教师引导学生明确：图中的圆柱在不同高度横切，得到的圆大小相同；图中的圆锥在不同高度横切，越靠近顶点，得到的圆越小，越靠近底面，得到的圆越大。
师：刚才的观察与你的猜想一致吗？请你把发现指给同桌看。
[h2]（三）比较竖切的截面，关注切割位置
师：再看后两组。圆柱竖着切，几个面都是长方形，它们的大小就一定相同吗？请你指着图说说自己的想法。
学生观察图中的切割位置。教师将两个相同的圆柱容器横放，借助不同水量形成的水面进行演示，引导学生比较长方形的宽窄。
教师小结：图中圆柱竖切得到的长方形可能大小不同，切面越靠近中间，长方形越宽。如果学生提出两个不同位置的截面也可能一样大，教师结合两侧对称的位置予以说明，提醒学生要看具体的切割位置。
师：圆锥竖切的这组图，你还有什么想问的吗？
学生提出疑问，教师展示课前按图示位置切开的圆锥模型，让学生观察各个切面并比较大小。教师引导学生看到：这组图中不同位置的切面大小有差别。
如果学生认为圆锥竖切后的面都是三角形，教师请学生对照模型看看切面有没有经过顶点。教师指出，经过顶点的竖切可以得到三角形；图中偏离顶点的切面不能都看成三角形。本课不要求学生给每一种截面命名。
[h2]（四）回顾比较过程，整理发现
师：现在，请你再看看自己的记录。判断切面大小时，除了看立体图形的样子，还要留意什么？
教师引导学生结合刚才的活动，说明还要留意怎样切、从什么位置切。学生对照实验结果修正记录，教师将学生的发现补充在相应板书旁。
[intent]【设计意图】教师将截面的形状问题推进到大小问题，引导学生关注切割位置。学生通过比较和验证说明理由，逐步把截面的特点与立体图形联系起来。
[h1]四、运用观察方法，完成练习
[h2]（一）完成连线，说明截面形状
师：请同学们完成教材第80页第1题。你先看清每幅图怎样切，再想象切开后的面，最后连一连。
[img]exercise1
学生独立连线，再选择一幅图说明理由。教师核对：按题图给定的切法，左图连长方形，中图连圆，右图连正方形。
如果学生根据立体图形的名称直接判断截面，教师请学生重新指出切入的位置，结合图中这个面进行比较。
[h2]（二）联系生活，比较截面大小
师：请看第2题。按A、B、C的顺序切图中的萝卜，切面大小会怎样变化？
[img]exercise2
学生结合图中萝卜从尖端向下逐渐变粗的样子作出判断。教师引导学生明确：A处的切面最小，B处比A处大，C处最大。学生对照连线，说明自己的判断依据。
[h2]（三）回顾学习，交流收获
师：同学们，今天我们从切开立体图形想到了不同的平面图形。回想一下，哪一次观察让你改变了原来的想法？请你说说当时怎样验证的。
学生交流验证记录。教师结合学生的说明，提醒学生看清观察方向。
教师请学生对照记录自查：自己能否说明图示截面的形状，能否讲清验证办法和大小比较的依据。学生把仍有疑问的地方做上记号。
[h2]（四）布置课后练习
1. 学生选择本课的一幅切割图，向家人说明自己的猜想及验证办法。
2. 学生可在成人帮助下重复水面实验并记录发现，学生不自行使用刀具。
[intent]【设计意图】学生把本课方法用于教材练习，在说明理由时检查自己的理解。教师通过学习记录了解学生的变化，鼓励学生对尚未解决的问题继续观察。
[h2]板书要点
教师在课题下记录图示结果：横切得圆，竖切得长方形，斜切得椭圆。
教师补充板书：切法与位置影响截面，学生可以借助水面验证猜想。
