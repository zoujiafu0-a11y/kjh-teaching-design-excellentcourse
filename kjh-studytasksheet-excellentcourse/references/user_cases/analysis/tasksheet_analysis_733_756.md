# P00733至P00756逐课分析

## 四季续P00733
第二课时末先唱《四季歌》，第五任务由前面课文插图仿句到仿写小诗，AI小画家给小诗配动画。原句“仿照课文写小诗，AI小画家为小诗配上动画。”把写作依据明确为课文，AI是配图角色；工具和动画是否可用未在本任务验证，不能宣称已实现。

## 四季另一套P00734至737
第一课时三目标，预读；故事争论引题，寻找四季数小节并圈谁说话，欣赏春夏各节中识字、古今字连线、词串、偏旁、节气对比，配乐读评分与新儿歌识字，末四小书空对比描写评价。第二课时故事词语复习，秋谷穗鞠躬着短语，冬顽皮分类和地多音字，配乐全文，叠词到儿歌到偏爱季节，再回答开头争论；末鸟是天观察色块范写描写反馈。原句“回答小动物们的问题，到底哪个季节最美好？说一说自己的看法。”使终点回应起点；不移走争论情境单加结论。原句“读得正确一颗星，读出草芽和荷叶快乐的心情一颗星！”两维评分是局部朗读要求，不换为统一评分量表。两课时书写分配与前套不同。

## 语文园地五第一套P00738至743
第一课时两目标，预学联系四篇四季课文；课堂运用十二词读、分行发现类别、学伙伴说话、自选词说，然后惜时名言拼读变调并想含义。原句“选择词语，学着学习伙伴和同桌说一说，也可用自己喜欢的方式说。”同时保留范例与表达选择。资源书封面小字不全清；《明日歌》署名等只是原资源未独立考据。
第三课时四目标，先六对反义词、生活发现、游戏、描写评勋章，再拔萝卜听标段、共读、图预测、小组编结尾。原句“借助插图，猜一猜故事后面的内容。”猜测不是原故事事实。第二课时三目标，姓名卡预学，按季节分组主动交友、观察范例、四标准评选，再收集姓名牌交流识字方法与赛跑。P00743显示实际班级姓名牌组合，无法证明虚构，按潜在真实学生名单排除公开原图并去名；本地保留。P00742插图对话属教材示范不是真实学生记录。

## 语文园地五第二套P00744至746
识字加油站两目标，课前空白，三任务读词、自选方法识字和积累反义词、写四字撇点；口语交际两目标，制作姓名卡，课堂忆交友、看插图和老师学方法、主动介绍聊天。原句“忆交友：回忆自己的交友经验。”不能预写新学生过去交友经历。综合课四目标，姓名卡预学，四任务说四季、姓名卡花名册小组认名比赛、背惜时名言、图续编拔萝卜；没有实际花名册附页，不编制名单。不同园地课时安排分别保留。

## 雨点儿P00747至748
页眉为之江汇教育广场，与前面基础教育精品课不同。第一课时三目标，认字书空预学；四任务听读标段自读、逐段随文识字并数不清生活仿说、第五段停顿、半来三看写。第二课时三目标，复习字与书空你有；三任务复习首段、大/小雨点对话用直线波浪线分角色、书写。原句“用‘___’画出大雨点儿说的话，用‘~~~’画出小雨点儿说的话，说说发现，分角色朗读。”不同标记区别角色服务朗读。第二课时书写任务仍半来，与目标你有冲突，存疑不直接迁移。三看法细则未写，不能编造三看内容。

## 比尾巴第一套P00749至751
第一课时三目标，无预学，四任务读标节、读问句画比赛项目、读并圈动物、观察共同点笔顺写比巴。第二课时三目标，无预学，三任务读画圈复习、问答游戏及仿儿歌、写长公。原句“画：用‘___’画出比赛项目。”和“圈：用‘○’圈出参赛的小动物。”分别检索项目与对象，不能合并抹掉句子功能。问答图中比较鼻眼爪不只尾巴，迁移前核实图对象及句型。

## 比尾巴第二套P00752至755
第一课时三目标，预读，五任务标小节、六动物图字连线、读一二节问句、猫鼠燕尾巴比较创编、写长比。第二课时背一二节预学；背、读三四节、兔猫象耳及鸟鸭兔嘴比较创编、写巴公、背全文五任务。原句“观察比较动物的特点，创编儿歌”允许比较耳嘴形状，本例图片提供依据；不能把标题尾巴概括为所有图只能比尾巴。嵌入教材小图全文未全部辨清，P00752至754保留PARTIAL_SMALL_TEXT，不能OCR乱码充核实。

## 乌鸦喝水第一课时P00756
四目标，拼音预读；课堂三短任务阅读识字、提取原因信息解释、练习书写；资源无。原句“提取文中明显信息，解释乌鸦找水喝及喝不着水的原因。”以文本证据说明因果，不转为物理实验事实。具体生字只个与教材对应，不能把其他案例字移来。
