# P01069—P01092 逐课核对
24页原图逐页查看，OCR全行已读。新增真实身份页P01079、P01084、P01087，只记录字段种类，不抄身份值。

## 《搭船的鸟》乙版续 P01069—P01072
接前页静态观察，小蜗牛推荐卡保留“整体、局部、特点”，先整体颜色，再触角比喻、壳。第二课时读问句体会好奇，看片排序五张捕鱼动作图，圈动词做动作，对比菁莽《翠鸟》语段，再找时间词，填翠鸟日常小剧场。之后观看蜗牛过马路视频，写动态过程，最后独立做喜欢动物的完整推荐卡。评价10星：明星小档案2星、颜值4星、日常小剧场4星。原句“根据‘动物推荐卡’评价表，为喜欢的小动物完成推荐卡，挑战10颗星。”前承静态和动态两次迁移，后接卡纸画图贴照要求。数量与星级有明确原页依据，应保留，不能擅改成无数量回应；前置观察动作至少3个也属于本课特定要求。原推荐资源《鸬鹚》与翠鸟的关联说法应保留为源文信息，引用为新课事实前另核，不自动纠正也不当已证事实。

## 《金色的草地》 P01073—P01076
第一课时读第二段勾词想象玩耍，观看兄弟视频选喜欢情景说话，观察生字并每字练一遍。第二课时默读第3段勾颜色变化完成课后第2题，再梳理“发现变化，引发疑问／仔细观察，找到原因”，最后边看视频做动作、朗读。两课时的任务单没有强制评价修改栏目。原句“你最喜欢哪个情景？用自己的话描述出来。”前承视频，功能为个人选择后的口头表达。视频和绘本未附，不能生成观看结果。

## 《那次经历真难忘》 P01077
课前回忆真实经历，可借照片、向共同经历者询问。课上先借乐乐经历分享选材、快放电影讲完整，再借扳手腕慢放电影定格3核心画面，按顺序连起来写过程，读例文学心情词与内心想法，修改片段。末句请身边人从过程清楚、难忘心情、标点正确三角度提建议。三个画面有本课依据，不能无限扩增；乐乐、扳手腕例文未附，不能伪造为已读完整文本。“把定格的画面按顺序连起来，用几句话描述每个画面的内容，写清经历的过程”从提取画面过渡到成段，换新经历时保留此功能，画面事实须学生提供。

## 《口语交际：请教》 P01078
课前记录真实小问题；课上先记录四把金钥匙，再选请教者／帮助者演练，伙伴按礼貌大方、表达清楚、积极互动画星。原句“我的角色：在小组演练中，我扮演的是 □请教者 □帮助者”把角色勾选置于评价之前，不能省为泛泛分组。评价语“能认真倾听，并适当追问或回应”兼顾两个角色，不强造书面改稿。四把钥匙内容在目标已经写明，但答题空不能预填成真实学生已学会。

## 《司马光》 P01079
有真实学生身份组合，公开去除身份。课前仅准备语文书、钢笔、田字格；课上解题复姓、明特点知文言、四锦囊“读准读通／读出节奏／读懂意思／熟读成诵”、感悟品质、寻找故事传讲人。此页大量任务仅标题，不能补造全部操作和填写区后称严格模仿。锦囊顺序保留，阅读理解发生在朗读节奏后、背诵前。

## 《一定要争气》 P01080—P01083
第一课时字词认读，由科学家与早年成绩反差提问，全文找“争气”词句、定位场景，分段提炼情况做法，对比“为自己／为国家”，信息支架讲故事。原页有“四次想到”与后文“两次争气”的口径差异，记录待教材核对，不自行消除。第二课时附《数星星的孩子》全文，先读童第周中学困境关键词“再三／才”，再学习勤奋细节与内心独白，留学国家背景、实验攻关，再与张衡对比，延展邓稼先袁隆平、真实个人故事。想象科研场景属于想象任务，不得转成已核实历史细节。生平、实验难度和推荐纪录片仅为本页陈述，外部链接未访问。

## 《手术台就是阵地》 P01084—P01089
两课时首页填写真实身份组合，公开排除原图。第一课时预学背景、担架重担大夫大声、陆续继续连续选词梳理、战争词、人物词。课上预学反馈写字评价、情节路线图串主要内容，再自学2—5段环境词句，群学并用支架汇报。P01085嵌入教材两页微字未完全可辨，路线旗帜“战斗打响／坚守阵地／胜利结束”和起因经过结果清晰。P01086原句“我们小组找到的是____（句子），我们从____（词语），感受到（觉得、明白、懂得）____。”连接句子、词语和感受，三空不可只填抽象品质。
第二课时行为先行、语言随后。波浪线画2—4段行为，找关键词，四行战场环境与右列白求恩表现对应；再交流“在____的战斗环境下，白求恩____（怎么做），我们从____这些关键词，感受到____，我们觉得这是一个____的白求恩。”按环境到行动、语言证据到人物判断展开。之后第3段对话理解题意，短支架“我找到的是____这句话，从中我体会到____。”与前长支架区别保留。P01089实际纯空白，并非OCR漏读。

## 《一个粗瓷大碗》 P01090—P01091
课前识字多音字，课堂带问题默读圈信息标生词，文物故事卡用三时间点对应通讯员和赵一曼行为，最后重读感动语句谈品质。原句“课文围绕‘粗瓷大碗’讲了什么事？请你根据‘文物故事卡’的提示理一理。”前承初读问题，后接过程卡，文物而非人物传记贯穿主线。推荐电影、书、馆仅原材料资源范围，不能声称已经参观或核验陈列。

## 《这儿真美》开篇 P01092
课前拍摄收集一处照片、实地多感官观察，课上景点名片记录“什么地方／有什么／什么样子”，推荐者与照片区空白。后续页待读，不能把本页当整课终止。照片和实地经历须真实输入。
