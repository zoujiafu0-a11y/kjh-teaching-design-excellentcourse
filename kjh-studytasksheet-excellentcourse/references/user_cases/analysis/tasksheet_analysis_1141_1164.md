# P01141—P01164 逐课核对
24页原图及OCR全行已读。本批未新增真实身份。P01162学生栏为空。

## 《我是什么》 P01141—P01144
第一课时预习认字调查、教师学情分析，正文含若干字识记率不到50%，这是源课调查陈述，不能移作新学生事实，问卷原数据未附。课堂出声读标段圈字、自主识字交流、圈水变化并图名连线、第一段听读想象汽云、读画说再读。第二课时读说变什么怎样下来、填形态与动作、演读、交换落打飘辨准确、第三段生活水态与视频、第四段好坏事及四字词。句式“我变成了（），（）下来，人们叫我____（）。”先填形态、动作、名称，承接第二段，不能无依据补科学过程。动词互换只为比较表达，不得刻意改写作者用词。

## 《植物妈妈有办法》 P01145—P01148
课前至少两遍、3—5有趣词、实地观察拍画并猜传播方式；课上情境图、质疑、字词得、圈植物名、分节蒲公英苍耳、书写。第二课时植物名片猜、石榴豌豆学习、整合、金牌讲解员、末节道理及仿说。原句“在小区、公园或路边，寻找一种你认为‘会旅行’的植物，仔细观察它的样子，猜想它的种子可能会用什么方式离开妈妈？用画图或拍照的方式记录你的发现。”观察和猜想分开，不能把猜测写成已证传播机制。教材版本和石榴等对象仅记录源课，不能套用其他版本。

## 《快乐读书吧：读读童话故事》甲 P01149—P01150
课前无；课上看封面猜及选书理由、读内容验证猜测可求助师生或AI、按时间页数计划读书及读后记录、读前中后爱护图书。原句“读完一本书后，尝试制作‘读书记录卡’，记录自己印象最深刻的内容、自己的疑问，或是遇到的问题和解决的办法。”阶段明确读完后，不可预填成已完成阅读。

## 乙 P01151—P01152
前置自带喜欢童话书、翻封面插图；封面发现家说书名作者出版社插图、用《孤独的小螃蟹》猜内容、共读《咚咚鼓》听开头猜物再猜后续、角色朗读体心情、参考范例为手中书设计计划。灰字文字原图可读，OCR噪声多，主视觉核对补足。未附完整《咚咚鼓》与范例计划，不将未见材料当已读。无甲版爱书四阶段与AI求助的强制迁移。

## 《语文园地一》三组 P01153—P01161
第一组课前天气植物、识字方法、左右结构、梅花预读；课堂天气九词、多法生活理解、模拟播报九城市符号（为题设天气，无日期，不能报成实时预报）；转夹和海作都别描临评改；梅花读准、节奏、插图想象、冬景联系、提示背诵和图背。保留字帖红色描写与空格，不能用普通写作框替换。
第二组实为口语交际动物，虽同题语文园地一，独立保留。声音局部谜语猜友、说喜欢动物、导图趣处、乐乐蜗牛示范、建议后重新讲、组内到班级展示。原句“大家有没有不明白的地方？”放介绍末尾邀请提问，前承动物特点，不能只给单向演讲。口头重讲有本课依据，非普遍作文重写。
第三组读演辨迎追、穿披、甩摇，填图动作、速度排序、语境选动词，再借我是什么例句迁移“有时候……有时候……”“在……在……在……在……”讲真实日常；企鹅寄冰从标题疑问、自读、解疑到质疑仅讲水变化是否够，再温差、地图科学教师解释、转化口吻给企鹅说明。跨学科讲解材料未附，不能自造当已读教材，非洲气候不能从本页一句概括扩成全境恒温。

## 《江雪》 P01162—P01164
预习识字和诗人信息，听范读说感受、五言节奏、前两句图意与千山万径虚指类比、单元词语选诗境、感受朗读、观察范写练字自评。P01164只有页眉与空表尾，实际查看确认。原句“读本单元语文园地词语，选出与诗境相关的词语。”前承诗意，后接全诗朗读，需文本依据选择而非随意堆情绪词。
P01163推荐诗署柳宗元《渔翁》，内容“一山一水一云天……”与标题归属待核验。原图明确如此，不能OCR纠错方式抹去，也不能当已核实古诗迁移。推荐译文同属未核署名文本的解读，不扩成权威依据。
