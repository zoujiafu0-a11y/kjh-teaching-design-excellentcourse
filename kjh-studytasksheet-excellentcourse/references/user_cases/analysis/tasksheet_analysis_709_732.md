# P00709至P00732逐课分析

## 语文园地二另一套P00709至712
第一课时两目标，复习六韵母四声及声母词；两任务分别四组不同声调读、bd与ft形近比较，九字按韵母a/i/u连线再读。原句“连线后再次朗读，感受字的读音与韵母读音间的联系。”后读承担关系体会，不是强制评价后重读。第二课时识字写九王及背《画》，预学区分拼音本已填/待填信息并试写新笔画；课堂两句短任务。第三课时单目标，预学共读，课堂读懂故事和分角色读演两项。原句“在大人的帮助下，阅读《小白兔和小灰兔》，了解故事内容。”目标与第一任务直接复用，不能为避免重复擅改。

## 秋天P00713至716
第一课时四目标，两项预学，四任务先变调轻声儿化音，再标自然段，读首段识字，写了子。第二课时三目标，读文背首段预学，课堂复习词及图片背首段、读二三段识飞到全文背及秋天来了句式、写大人。原句“知道‘一会儿’是个儿化音，知道它的注音方法，读准‘一会儿’。”语音知识与读音目标明确，不转一般句式创新。资源栏XXX为占位，不能当真实资源。填空、图片背诵支架未见具体图片，留缺项。

## 江南整课P00717至718
三目标，课前读通古诗，四任务听读通顺、方位词句支架并找四词关系、提示背诵与有情朗诵、描二写一和莲蓬三维评价。原句“生字描两个，写一个。争取做到正确、美观、整洁。”后表对应书写正确、字迹美观、卷面整洁，数量与评价一致，不擅自改描写次数。方位需依诗歌顺序，评价未要求重写。

## 江南分课时P00719至722
第一课时三目标，四任务初读江南三点水、莲采字形趣读及生活拓词、选宣传画说理由与入境读视频选图说、写可叶自评。原句“为‘莲池’选一张宣传画，说说理由。”依候选图，未附图须补真实材料或标待补，不能编造图内容。第二课时三任务趣味识字间/方位/戏词树，想象鱼活动表演配乐读与图背，写东西自评。原文把“竖钩”“竖弯”叫新偏旁，属于笔画术语疑误，存档不篡改，新稿应核实不直接复用错误。与整课版目标范围、顺序不同，各自保留。

## 雪地里的小画家第一套P00723至726
前半三目标，无预学，五任务圈画家名字、四动物列举句式、圈作品随文识字笔画、提示背前三句、写竹牙马。后半三目标，无预学，六任务脚印配对说画、读思怎么画、按原诗空格仿编、青蛙冬眠识没参加、情境背诵、写用几。原句“自由朗读课文，思考：雪地里来了哪些小画家？用笔把他们的名字圈出来。”问题指向文本检索，圈名作为产出。两份标题均未标课时，内容连续不能擅认缺失。图文提到脚印但页未附配对图，留材料缺项。

## 雪地里的小画家第二套P00727至729
第一课时三目标，课前拼音读字；四任务我会读准字音给词、我能读好句子给开头、我会提取信息找画家把名片放作品下、我会正确书写描写格。第二课时先复习字音和三句编写的迁移句，再主问题“画家怎么画”，看图、想关系、同伴说并因果支架，图式挖空背全文、写用几。原句“因为___脚印像___，所以___。”承担解释依据，不当研究结论。冬眠事实须新教材科学依据核对。第二套没有前套独立仿编整首任务，不拼合。

## 四季P00730至732（第二课时未结束）
第一课时四目标，无预学，任务顺序先写四，再自主方法识字，再课文插图找形象/动作读/夏池塘仿句，末写小鸟附姿势图。原句“夏季的池塘里还能看见谁，它是什么样的？仿照课文的句式说说。”保持特定季节场景的迁移边界。第二课时四目标含AI配图、多形式读和创编；已读首面先复习学法、想鞠躬演雪人、写是天、动作读提示背；后续页未读，不判断整课目标缺项。AI是此课原安排，不能据此要求其他任务单默认增加AI。
